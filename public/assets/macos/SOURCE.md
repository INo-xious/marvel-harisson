# Mac desktop artwork

Converted from the installed Apple macOS system artwork for the requested Mac-style portfolio desktop:

- `sonoma.webp`: `/System/Library/Desktop Pictures/Sonoma.heic`
- `finder.webp`: `/System/Library/CoreServices/Finder.app/Contents/Resources/Finder.icns`
- `folder.webp`: `/System/Library/CoreServices/CoreTypes.bundle/Contents/Resources/GenericFolderIcon.icns`
- `notes.webp`: `/System/Applications/Notes.app/Contents/Resources/AppIcon.icns`
- `calendar.webp`: `/System/Applications/Calendar.app/Contents/Resources/AppIcon.icns`

Wallpaper is resized for web delivery; icons retain transparency. Apple is the source of this system artwork. The portfolio desktop is a browser interface styled after macOS.
